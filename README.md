# 숨결 편집기 (M1, 2026-11-06)

쇼츠 작업용 개인 영상 편집기. Windows PC에서 브라우저로 써요.

## 폴더 (11-06 "폴더 통일해" — 두 PC 모두 같은 구조)
```
<구글 드라이브>\01_쇼츠\
  sumgyeol_editor\       ← 편집기(여기서 START.bat 실행)
    projects\           ← 프로젝트 .shum (두 PC 공용, Claude도 Drive로 읽어요)
  sources\<편 번호_주제>\ ← 원본 클립·내레이션·자막 (두 PC 공용). 받은 영상은 sources\_받은영상\
  지구의숨결\#N_주제\    ← 최종 mp4·커버
  tools\                ← 인스타 게시 도구 등
이 PC에만: %LOCALAPPDATA%\sumgyeol\  ← 편집용 저화질 사본, ffmpeg (동기화 안 함)
```
- 다른 PC에서 저장한 프로젝트를 열면 클립을 `sources` 안 경로로 자동으로 다시 연결해요. 그래서 **원본 클립은 꼭 `01_쇼츠\sources\` 안에** 두세요.

## 켜기
1. 구글 드라이브의 `01_쇼츠\sumgyeol_editor\START.bat` 더블클릭(오른쪽 클릭 → "오프라인 사용 가능"으로 해 두면 빨라요).
2. 처음 한 번은 이 PC에 ffmpeg(약 150MB)를 받아요(`%LOCALAPPDATA%\sumgyeol\bin`).
3. 브라우저에 http://localhost:7800 이 열려요. 검은 창을 닫으면 꺼져요.

## 키 파일 (대본 추천·영상 찾기용, 채팅에 붙이지 마세요)
`C:\Users\<내 이름>\.sumgyeol_keys.json` 파일을 메모장으로 만들고:
```json
{"anthropic": "sk-ant-...", "pexels": "...", "pixabay": "..."}
```
- Claude API 키: https://console.anthropic.com (대본 추천에만 씀, 쓴 만큼 요금)
- Pexels API 키: https://www.pexels.com/api/ (무료)
- Pixabay API 키: https://pixabay.com/api/docs/ (무료, 로그인 후 페이지에 보임)
- (11-07) 키는 `01_쇼츠\_private\sumgyeol_keys.json`(구글 드라이브)에 저장돼 두 PC가 같이 써요. 예전 PC 파일(`~\.sumgyeol_keys.json`)에 있던 키는 처음 켤 때 자동으로 옮겨요. 이 파일은 남과 공유하지 마세요.
- 없는 키는 빼도 돼요. 오른쪽 위에 ✓/✕로 보여요. 모델을 바꾸려면 `"model": "claude-sonnet-5-5"`처럼 추가.

## M1에서 되는 것
- 파일 가져오기(PC 파일 고르기 창) → 편집용 저화질 사본(한 번에 2개씩, 오른쪽 아래에 남은 개수 표시)·썸네일·파형 자동 생성. 원본은 그대로.
- 트랙 3개(글자·영상·소리). 미디어를 끌어다 놓기(더블클릭 = 맨 뒤에 붙이기), 끌어 옮기기, 양 끝 잡아 늘이기·줄이기, 자석 붙기.
- 재생(스페이스), ←/→ 한 프레임(Shift = 1초), S 나누기, T 글자, Delete 지우기, Ctrl+Z/Y, Ctrl+S 저장.
- **켜 둔 채 자동 업데이트**(11-06): 3분마다 새 버전을 확인해 재생 중이 아니면 저장 → 적용 → 같은 프로젝트로 새로고침. 껐다 켤 필요 없어요.
- **서서히 나타나기/사라지기**(11-06): 속성 칸의 초 수(영상·소리·글자 모두, 소리도 같이 줄어요). "앞 영상과 겹쳐 바뀌기" = 0.5초 크로스페이드, 아래 "◐ 전환 일괄" = 모든 영상 사이 0.5초 + 처음 0.4초 나타나기 + 끝 0.6초 사라지기. 타임라인 클립 끝의 어두운 그라데이션이 페이드 표시예요.
- 속성: 시작·길이·원본 시작·속도·음량, 꽉 채우기/전체 보이기·확대·위치, 글자 내용·크기·색·위치·외곽선.
- 화면 비율 9:16 / 16:9 / 1:1. 프로젝트는 `projects\이름.shum`(JSON, 4초마다 자동 저장).
- **영상 먼저 → 대본**(11-06 "영상을 찾아서 - 대본을 추천하는 방식으로"): 대본 추천 탭에서 채널·주제 → ① 주제로 영상 모으기(Claude가 검색어 8개 → Pexels·Pixabay에서 받아 `01_쇼츠\sources\지구_주제\`, 출처는 그 폴더 credits.json) → ② 이 영상들로 대본 추천(Claude가 클립마다 3장을 직접 보고, 문장마다 맞는 클립·시작 초를 골라 대본을 씀) → 타임라인에 배치(자막+영상, 길이는 글자 수로 어림) / 대본 저장(그 폴더 `대본.json`·`대본.txt` → Claude가 내레이션을 만들어 실제 시간으로 다시 맞춰요).
- **대본 추천(영상 없이):** 채널(지구의숨결·소방해부학, `channels.json`에서 규칙 고침) + 주제 → 주제 후보 3개와 문장별 대사·영어 자막·근거·검색어.
- **출처(11-06 "다른 저작권없는 신기한 영상들도"):** Pixabay(키), 위키미디어 공용(키 없음, 퍼블릭 도메인·CC0·CC BY·CC BY-SA만 — 출처 표시 필수, BY-SA는 같은 조건 표시), NASA(키 없음, 대부분 퍼블릭 도메인 — NASA 로고·제3자 자료는 제외), Pexels(새 키 발급 중단 → 주소로 받기). **✨ 신기한 영상 둘러보기** = 신기한 자연·우주 현상 검색어 6개를 골라 모든 출처에서 찾아 보여 줘요(영상 먼저 → 주제 고르기).
- **사용 조건 고려**(11-06 "사용조건까지 다 고려해서 영상 추천"): 영상 찾기 탭 위 선택 — "출처 표시하면 되는 것까지"(기본) / "조건 없는 것만". "검토 전 포함"을 켜지 않으면 위키미디어의 라이선스 검토 전 파일은 빼요. 결과는 안전한 순서(조건 없음 → NASA → 출처 표시 → 출처+같은 조건)로 보이고 카드에 색 배지가 붙어요. 영상 모으기·신기한 영상·검색 모두 같은 기준. 대본 추천 탭 "📋 이 폴더 출처 문구" = 업로드 설명란에 붙일 출처(작가·라이선스·링크) 자동 작성.
- **🔗 이어 붙일 비슷한 영상**(11-06): 미디어 카드 오른쪽 위 🔗 또는 타임라인 영상 클립 속성의 "🔗 이어 붙일 비슷한 영상 찾기" → Claude가 그 영상 장면 3장을 보고 검색어 6개(같은 대상 다른 각도·가까이, 다음 행동, 사는 곳 넓은 장면, 관련 생물·현상)를 만들어 사용 조건대로 여러 출처에서 찾아요. 이미 받은 영상은 빼요. 키가 없으면 파일 제목 낱말로 찾아요.
- **찾은 영상 한 줄 한국어 설명**(11-06): 카드 맨 위에 무엇이 나오는지 한국어로(Claude 키가 있으면 제목·태그를 보고 요약, 없으면 검색어 이름).
- **받으면 바로 대본 추천**(11-06, 기본 켜짐): 받기를 마치고 8초 동안 더 받지 않으면 그 폴더 영상들로 대본을 추천받아 타임라인에 자막+영상으로 넣어요. 주제·폴더 칸이 비어 있으면 받은 영상의 주제로 채워요.
- **영상 찾기:** 검색 → "받아서 넣기"(받은 파일은 `01_쇼츠\sources\_받은영상\`, 출처는 같은 폴더 `credits.json`과 속성 칸에 자동 기록). 대본의 "문장마다 영상 자동으로 가져오기"는 문장마다 첫 검색어의 첫 영상을 받아 차례로 놓아요.
- 대본 → "자막으로 넣기"로 글자 트랙에 문장별 자막.
- **자막(.srt) 불러오기**(11-06 "소리를 듣지 않고 자막으로 제어"): 내레이션 자막을 글자 트랙에 문장 번호와 함께 깔아요. 소리를 안 들어도 자막 칸을 보고 영상 클립을 그 아래에 맞춰 놓으면 돼요.

## 🎬 미리보기 영상(11-07)
맨 위 "🎬 미리보기 영상" → 지금 편집 그대로 실제 속도로 재생하며 녹화(화면+소리) → `01_쇼츠\sources\<편 폴더>\미리보기_<이름>.mp4`로 저장하고 바로 열어요. 녹화하는 동안 그 탭을 띄워 두세요(다른 탭으로 가면 끊겨요). 검토·공유용이고, 최종본은 Claude가 원본 화질로 렌더해요.

## 문장 탭(11-06 "자막을 고치고 코멘트로 영상·사진·Veo 요청")
문장(자막)마다 한 칸: 번호·시간·지금 화면 썸네일 / 글 고치기(바로 반영) / 코멘트·요청 칸 / 버튼 3개.
- **🎬 쓸만한 영상**·**🖼 어울리는 사진**: Claude가 문장(+코멘트)으로 검색어를 만들어 사용 조건대로 찾고, "이 문장에 넣기"를 누르면 받아서 그 문장 구간의 영상 트랙을 바꿔 줘요(사진은 천천히 줌인, 짧은 영상은 살짝 느리게 채움).
- **✨ Veo 만들기**: 이 문장용 Veo(Flow) 영어 프롬프트 + 샷·카메라·빛 설명 + 요령 + 검수 항목. 복사 → Flow(9:16·8초)에서 만들기 → **📥 Veo 클립 넣고 검수**로 받은 파일을 고르면 그 문장에 넣고 Claude가 장면 4장을 보고 검수(점수·문제·고친 프롬프트). AI 클립은 렌더 때 "AI 재현" 표시, 유튜브에 "합성 콘텐츠: 예".

## 🎬 대본에 맞춰 영상 재배치(11-07)
문장 탭 맨 위 버튼. 이 편 폴더(sources\\<편>)의 영상·사진과 지금 타임라인 클립을 Claude가 직접 보고(영상 3장·사진 1장), 고친 대본의 문장마다 가장 맞는 클립과 시작 초를 골라 다시 붙여요. 짧으면 살짝 느리게. Ctrl+Z 한 번이면 전체 되돌리기. Claude 키 필요.

## 💬 클립 코멘트로 고치기(11-07 "영상을 클릭해 코멘트 남기면 수정")
영상·사진 클립을 클릭 → 오른쪽 속성 칸 "💬 이 장면 코멘트"에 적고 **🤖 이 코멘트대로 고쳐 줘** → Claude가 지금 장면과 이 편의 다른 클립을 보고 ① 다른 클립으로 바꾸기 ② 구간·확대·위치·속도 조정 ③ 새 영상 찾기(영상 찾기 탭에 후보) ④ Veo 프롬프트 중 하나를 해요. **대본(글자·목소리)은 절대 안 바꿔요.** 무엇을 했는지 한 줄로 알려 줘요. Ctrl+Z로 되돌리기.
- 🎬 대본에 맞춰 영상 재배치도 영상 트랙만 바꾸고 대본은 그대로예요.

## 🔊 목소리(11-07 "음성도 자막 넣을 때 같이")
- (11-07 "높낮이가 너무 다르고 어색") 문장마다 32단계로 최대 3번 만들어 평소 높낮이(약 110Hz)에 가장 가까운 것을 고르고, 빠르기(초당 6.3음절)·크기(-16 LUFS)를 맞춰요. 초안의 옛 내레이션과 섞이면 어색하니 **🔊 모든 문장 목소리 다시 만들기**로 한 번에 통일하세요.
문장 탭에서 문장마다 **🔊 목소리** → 그 글로 8번 목소리(Supertonic, 이 PC에서 직접)를 만들어 소리 트랙에 넣고, 문장 길이를 목소리+0.45초에 맞춰 뒤를 밀거나 당겨요(영상도 같이 늘거나 줄어요). 숫자는 자동으로 한글로 읽어요(Claude 키가 있으면 더 정확). 틀리게 읽으면 "읽는 법" 칸에 직접 적고 다시 누르세요. 위의 "🔊 모든 문장 목소리 다시 만들기"는 전체를 차례로.
- 처음 한 번은 목소리 프로그램(pip sherpa-onnx)과 모델(약 85MB)을 받느라 1~3분 걸려요. 모델은 %LOCALAPPDATA%\sumgyeol\tts.
- 만든 목소리는 `sources\<편 폴더>\voice\`에 저장돼요(두 PC 공용).

## 편집 단축키 (프리미어와 비슷하게, 11-06)
| 키 | 하는 일 |
|---|---|
| S / C / Ctrl+K | 재생선에서 나누기(고른 클립, 없으면 재생선 위 모든 클립) |
| Ctrl+X | 잘라내기(뒤 클립을 당겨 빈틈 없앰) |
| Ctrl+C / Ctrl+V | 복사 / 재생선 자리에 끼워 넣기(뒤를 밈) · Shift+Ctrl+V 덮어쓰기 |
| Ctrl+D | 바로 뒤에 복제 |
| (미디어 카드 클릭 후) , / . | 그 영상을 재생선 자리에 끼워 넣기 / 덮어쓰기. 더블클릭 = 끼워 넣기 |
| Delete / Shift+Delete | 지우기(빈틈 남김) / 지우고 당기기 |
| Q / W | 재생선 앞부분 / 뒷부분 잘라내고 당기기 |
| 클립 **끝부분 더블클릭** / 빈 곳 더블클릭 | 뒤 클립과 붙이기(영상은 이 클립을 늘려서, 글자·소리는 빈 시간을 모든 트랙에서 빼서) |
| ↑ / ↓ | 이전 / 다음 편집점으로 |
| ← / → (Shift) | 한 프레임(1초) |
| + / − | 타임라인 확대 / 축소 |
- 버튼: ✂︎ 잘라내기 · ⧉ 복사 · 📋 붙이기 · **↔ 빈틈 메우기**(클립 사이 검은 틈 + 원본이 모자라 클립 끝이 검게 남는 것(타임라인에 빗금 표시)을 원본 앞부분·살짝 느리게로 채움, 자막·목소리 싱크 그대로 — 보통 이걸 쓰세요) · **⇤ 당겨 붙이기**(고른 클립의 트랙, 안 고르면 글자 트랙의 빈틈을 없애고 모든 트랙을 같이 당김 — 자막 사이 빈 시간 줄이기).
- 속성 칸 **속도**: 슬로 0.25×·0.5×·0.75×, 보통, 1.5×·2×·4× 빠르게(뒤 클립도 같이 밀리거나 당겨져요).
- 속성 칸 **줌**: 줌인(1→1.3)·줌아웃(1.3→1)·크게 줌인(1→1.6)·줌 없음. 끝 확대·끝 위치 슬라이더로 움직이며 줌(켄 번스).
